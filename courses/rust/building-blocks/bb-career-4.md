# Building Block: Job Search Strategy and Networking

Finding Rust jobs requires a different strategy than finding JavaScript or Python
jobs. The market is smaller but less competitive — fewer applicants per role,
higher signal-to-noise ratio. This building block covers where to find Rust jobs,
how to network in the Rust community, and how to run an effective job search.

## Readings

- [Rust Jobs Board](https://rustjobs.dev/) — the primary Rust-specific job board.
  Browse it weekly.
- [This Week in Rust](https://this-week-in-rust.org/) — weekly newsletter. The
  job section at the bottom is gold. Subscribe immediately.
- [Filtra.io Rust jobs](https://filtra.io/rust) — another Rust-focused board
  with remote filtering.
- [Companies using Rust in production](https://www.rust-lang.org/production/users)
  — the official list. Many of these hire remotely.

## Key Concepts

**Where Rust backend jobs actually are:**

| Category | Examples | Typical Roles |
|----------|----------|--------------|
| Databases / Infrastructure | Tikv, SurrealDB, Materialize, InfluxData, Fermyon | Backend, distributed systems |
| Blockchain / Crypto | Solana, Parity/Polkadot, Stellar, Nym, Fuel Labs | Core protocol, smart contracts |
| Cloud / DevOps | Cloudflare, Fastly, Fly.io, Vercel (Turbopack) | Edge compute, platform |
| Security | 1Password, Trail of Bits, Oxide Computer | Systems, security-critical |
| Fintech | Kraken, Ditto, Star Lab | Backend, trading systems |
| Developer Tools | Tauri, Zed, Astral (Ruff/uv) | Tooling, CLI, IDE |
| Embedded / IoT | Various (check embedded.rs job board) | Firmware, real-time |

**Networking in the Rust community (not "networking" as in schmoozing):**

1. **Join the Rust Discord** — introduce yourself in #introductions, help answer
   questions in #beginners. Being helpful is the best networking.
2. **Attend Rust meetups** — search meetup.com for local or virtual Rust meetups.
   Presenting a lightning talk about something you built in this course is a
   high-signal way to get noticed.
3. **Participate on the Rust Users Forum** — answer questions, share what you've
   learned. Link to your blog posts when relevant.
4. **Follow Rust engineers on social media** — Twitter/X, Mastodon, LinkedIn.
   Engage with their content. Comment thoughtfully on technical posts.
5. **Attend RustConf or EuroRust** — even virtually. The hallway track is where
   jobs happen.

**The job search funnel:**

```
Companies researched:     50+
Applications sent:        20-30
Recruiter screens:        8-12
Technical interviews:     4-6
Final rounds:             2-3
Offers:                   1-2

Typical timeline:         2-4 months active search
```

These numbers are realistic. Don't be discouraged by rejections — a 5-10% offer
rate is normal and healthy.

**Application strategy:**

1. **Warm applications > cold applications.** A referral from someone at the
   company is worth 10 cold applications. This is why networking matters.
2. **Customize every application.** Same resume template, but adjust the summary
   and skills emphasis for each role. Mention the company's product by name.
3. **Apply to "stretch" roles.** If you meet 60%+ of the requirements, apply.
   Job postings describe the ideal candidate, not the minimum.
4. **Track everything.** Spreadsheet with: company, role, date applied, status,
   next step, notes. Update weekly.
5. **Set a weekly cadence.** 5 applications per week during active search.
   Block time for it like you would for coding.

**When you don't have "N years of professional experience":**

Most Rust job postings say "3-5 years experience." If you've completed this
entire course, you have:

- Built 30+ projects including a production-grade capstone
- Published an open source crate
- Contributed to real Rust projects
- Implemented Raft consensus and distributed transactions
- Written design docs and done code reviews

Frame this confidently: "I've spent the last [N months] building production Rust
systems full-time through [course name]. My portfolio includes [specifics]."
Don't apologize for not having traditional employment history. Let your work
speak.

## Exercises

1. Create a target company list of 20 companies that hire Rust backend engineers
   remotely. For each: company name, what they build, how they use Rust, career
   page URL, and whether you know anyone there.

2. Join the Rust Discord and Rust Users Forum. Introduce yourself. Answer at
   least one question on each platform this week.

3. Set up job alerts on rustjobs.dev, LinkedIn (keyword "Rust engineer remote"),
   and This Week in Rust. Review new postings weekly.

4. Identify 3 people in the Rust community you admire. Follow them on social
   media and engage with one post from each (a thoughtful comment, not just a
   like).
