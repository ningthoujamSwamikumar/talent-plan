# Course Roadmap

The Rust Backend Engineering course is organized into four stages:

## Stage 1: Technical Foundation (Phases 0-7)

Build deep Rust expertise through progressive projects: language fundamentals,
systems programming, web development, production engineering, advanced patterns,
distributed systems, and a capstone project.

**Time**: 3-6 months full-time.

## Stage 2: Professional Credibility (Phases 8-9)

Establish your presence in the Rust ecosystem through open source contributions,
a published crate, a polished portfolio, and professional communication skills.

**Time**: 4-6 weeks.

## Stage 3: Interview Readiness (Phase 10)

Prepare for every stage of the interview process: Rust coding problems, system
design exercises, code review practice, behavioral questions, and take-home
assignments.

**Time**: 3-4 weeks.

## Stage 4: Job Search (Phase 11)

Execute a structured job search with real applications, active networking, and
offer negotiation. This phase runs until you accept an offer.

**Time**: 1-4 months.
